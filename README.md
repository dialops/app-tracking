# WPN — трекинг позиций по брендовому запросу

Позиции приложения WPN в поиске App Store и Google Play по запросу **«WPN»**,
плюс рейтинг и число оценок в каждой стране. Замер раз в сутки.

## Как посмотреть

Репозиторий приватный, поэтому живой ссылки нет — GitHub Pages из приватного
репозитория работает только на Enterprise-тарифе.

1. Скачай `index.html` (кнопка **Download raw file** на странице файла)
2. Открой его двойным кликом в любом браузере

Все данные вшиты внутрь файла, интернет нужен только для подгрузки библиотеки
графиков с CDN.

## Что где

| Файл | Что это |
|---|---|
| `history.csv` | вся история замеров, одна строка на стор × страну × день |
| `build.py` | собирает `index.html` из `history.csv` |
| `index.html` | готовая страница, её и открывают |

## Формат history.csv

Разделитель — точка с запятой. Пропущенное значение — `-`.

```
date;store;country;rank;rating;ratings;reviews
2026-08-06;ios;kz;3;5.0;8;-
```

| Колонка | Значение |
|---|---|
| `store` | `ios` или `android` |
| `country` | `ru`, `kz`, `ua`, `by`, `us` |
| `rank` | позиция в выдаче, `-` если приложения в выдаче нет |
| `rating` | средняя оценка в этой стране |
| `ratings` | число оценок |
| `reviews` | число написанных отзывов |

## Что отслеживаем

- **App Store:** id `6760790701`, страны kz, ua, by, us
- **Google Play:** package `team.wpn.app`, страны ru, kz, ua, by, us

## Оговорки про точность

**App Store.** Позиции считаются по публичному поисковому API Apple, а не по тому,
что видит человек в приложении на телефоне. Расхождение на пару позиций возможно.
Цифры сверены двумя независимыми источниками. Число написанных отзывов Apple через
этот API не отдаёт — колонка `reviews` для `ios` всегда пустая.

**Google Play.** Позиции снимаются напрямую с выдачи стора. Рейтинг по стране
показывается только там, где набралось достаточно оценок, — до этого в колонках
`rating`/`ratings` стоит `-`. Это не ошибка сбора.

## Пересобрать вручную

```bash
python3 build.py
```
